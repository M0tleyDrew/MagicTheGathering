SaltyBananaSlug's MTG Deck Editor — Windows x64
================================================

1. Extract the entire ZIP file before running the program.
2. Open "SaltyBananaSlugs MTG Deck Editor.exe".
3. Windows may show a SmartScreen warning because this early build is not
   code-signed. Choose "More info" and "Run anyway" only if you downloaded
   this copy directly from Drew's SaltyBananaSlug project.

The editor runs locally. Internet access is still required for current card
data and images from Scryfall, Archidekt imports, EDHREC suggestions, Moxfield
imports, and optional OpenAI assistance.

Optional AI advisor
-------------------
Open Settings in the app and enter your own OpenAI API key. On Windows the key
is encrypted for your Windows user account and is never included in deck files.
OpenAI API usage is billed separately from a ChatGPT subscription.

This is an unofficial fan-made deck tool. Magic: The Gathering card data and
images are supplied by Scryfall. Commander suggestions use EDHREC data. This
project is not affiliated with or endorsed by Wizards of the Coast.
